fix: add missing Flyway V3 migration and AttendanceStatus converter (TICKET-017)

Audited all 19 JPA entities against V1 schema. Found two mismatches:

1. SanctionStatus Java enum has 'cancelled' but PostgreSQL sanction_status
   ENUM only had ('unpaid', 'paid'). Created V3 migration to add it:
   ALTER TYPE sanction_status ADD VALUE IF NOT EXISTS 'cancelled';

2. AttendanceStatus Java enum uses 'default_status' (Java reserved word)
   while DB ENUM uses 'default'. Created JPA AttributeConverter to
   map default_status <-> 'default' for seamless persistence.

All other entities match V1 schema correctly:
- tontine_debt UNIQUE(tour_id, debtor_id, creditor_id) confirmed
- global_movement_view confirmed present
- asvosonk_reports role confirmed present
- All column definitions, enum mappings, and constraints verified
